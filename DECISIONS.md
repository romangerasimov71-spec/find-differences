# Решения (DECISIONS)

## Исходные условия
- **Текст задания обрезан** на разделе «Графика: библиотека предметов (SVG) — Мин…». Решил: минимум 40 предметов
  (сделано 43), каждый с вариантами цвета и «деталями», которые можно убрать/добавить — это и есть источники отличий.
- **dev.vk.com недоступен из облачной среды** (сетевые запросы к dev.vk.com / dev.vk.ru блокируются, WebFetch тоже).
  Поэтому первоисточником API взят официальный пакет `@vkontakte/vk-bridge@3.0.2` из npm (типы `dist/types/data.d.ts`,
  CHANGELOG): методы `VKWebAppInit`, `VKWebAppCheckNativeAds`/`VKWebAppShowNativeAds` (`ad_format: 'reward' | 'interstitial'`,
  `use_waterfall`), `VKWebAppStorageGet/Set`, события `VKWebAppViewHide/Restore`, `VKWebAppTaptic*`.
  Требования модерации — по известным правилам каталога VK Игр (см. раздел «Модерация» ниже); перед подачей
  стоит сверить их с актуальным чек-листом в кабинете dev.vk.com.

## Техника
- Чистый HTML/CSS/JS без фреймворков и сборщика: игра маленькая, так быстрее грузится и проще проходит модерацию.
- VK Bridge **вшит локально** (`src/js/vk-bridge.min.js`, 4 КБ, лицензия MIT в `tools/VK-BRIDGE-LICENSE`) — без CDN,
  игра не зависит от внешних сервисов. `VKWebAppInit` вызывается первым скриптом.
- Все вызовы моста идут с таймаутом 2,5 с (реклама — 30 с): вне VK игра не зависает.
- Вся графика — SVG-строки в `src/js/art.js`. Толщина контура 4 px (в координатах предмета), цвет `#1d2b5c`.
  Блики — белые полупрозрачные формы, тени — полупрозрачные эллипсы, без градиентов (одинаково быстро на слабых телефонах).
