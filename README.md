# Найди отличия: Новый год

Уютная головоломка «найди отличия» для VK Игр (и Одноклассников): две почти одинаковые новогодние картинки,
игрок тапает по местам, где они различаются. Вся графика — SVG в коде, без внешних картинок и сервисов.

- 36 уровней, 6 сцен, 43 нарисованных предмета, от 3 до 7 отличий.
- Подсказки, звёзды за точность, сохранение прогресса в облаке VK.
- Реклама VK: межстраничная между уровнями (не чаще раза в 3 мин), за вознаграждение — подсказки.

## Структура
```
src/            игра (index.html, css/, js/)
  js/vk-bridge.min.js   VK Bridge 3.0.2 (локально, MIT)
  js/platform.js        мост VK с таймаутами: Init, Storage, реклама, сворачивание
  js/art.js             библиотека SVG-предметов
  js/levels.js          сцены и генератор отличий
  js/audio.js           синтез звука и музыки (WebAudio)
  js/game.js            экраны, логика, подсказки, сохранения
tools/          проверки и генераторы (галерея предметов, превью сцен, автопрогоны)
vk-assets/      иконка 576, фавикон 32, обложка 1120×630, 4 скриншота 600×1200
DECISIONS.md    принятые решения и почему
```

## Запуск и проверка
```bash
# открыть src/index.html в браузере (сервер не нужен), либо:
npx serve src
node tools/check-levels.js          # все уровни корректны
node tools/play.js /tmp/out 1       # автопрогон уровня со скриншотами 390×844
node tools/vk-mock-test.js          # интеграция с VK Bridge на подставном мосте
node tools/make-assets.js           # пересоздать vk-assets/
./build.sh                          # dist/vk/ и dist/find-differences-vk.zip
```
Для запуска инструментов нужен Playwright с Chromium.

## Публикация
`./build.sh` → содержимое `dist/vk/` (index.html в корне) выкладывается на хостинг (например, GitHub Pages,
ветка `gh-pages`), ссылка указывается в настройках приложения на dev.vk.com, ориентация — книжная.
